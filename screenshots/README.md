# Screenshots

Empty until V1 is verified in a live session. Shoot these, in this order:

| File | Content |
| --- | --- |
| `before-light.png` | Stock ChatGPT, one long answer, light |
| `after-light.png` | Same answer, Dense preset, light |
| `before-dark.png` | Stock ChatGPT, same answer, dark |
| `after-dark.png` | Same answer, Dense preset, dark |
| `density-presets.png` | Balanced / Dense / Ultra Dense, side by side |
| `elements.png` | One answer containing H2, H3, list, inline code, code block, blockquote, table |

Rules so the pairs are actually comparable:

- Same answer, same window width, same zoom, same scroll position.
- Use a real answer with mixed content, not lorem ipsum — the point is a
  hierarchy that survives density.
- Full column width, no cropping to the flattering part.
- Before/after must be the same viewport height so the density difference is
  readable as "more content per screen".
